# LOCAL:ON Route Recommendation

LOCAL:ON은 지역별 로컬발견가능성과 장소별 현지인·외지인 순위를 기반으로
맛집, 관광지, 카페/베이커리를 조합해 여행 경로를 추천하는 모델입니다.

## Recommendation Flow

시도 선택
→ 시군구 로컬발견가능성 순위
→ 지역 선택
→ 카테고리 선택
→ 장소 후보 생성
→ 이동거리·시간대·카테고리 다양성 고려
→ 최종 경로 생성

## Features

- 지역별 로컬발견가능성 기반 지역 추천
- 현지인/외지인 순위 기반 장소 추천점수
- 맛집/관광지/카페·베이커리 통합 추천
- 식사 및 카페 시간대 반영
- 근접 관광지 중복 방지
- 관광지 세부분류 다양성 반영
- 출발지 미입력 시 지역 중심점 자동 설정

## Example

충청남도 서천군 / 당일치기 / 맛집 + 관광지 + 카페·베이커리

덕암스파
→ 하림각
→ 서천특화시장임시시장
→ 브라운핸즈송림동화점
→ 장항송림산림욕장
→ 국립생태원

## Run

```bash
python local_on_route_recommender.py \
  --sido 충청남도 \
  --sigungu 서천군 \
  --trip day \
  --categories "맛집,관광지,카페/베이커리"
